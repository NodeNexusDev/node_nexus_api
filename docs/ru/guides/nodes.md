# Управление нодами

Создайте ноду с SSH-данными, проверьте подключение, затем используйте UUID в
запросах метрик и выполнения. Список поддерживает offset- и cursor-пагинацию;
не смешивайте режимы. При фильтрации теги объединяются условием AND. Актуальные
схемы запросов и ответов смотрите в Swagger UI.
