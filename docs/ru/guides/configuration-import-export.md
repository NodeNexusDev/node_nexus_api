# Импорт и экспорт конфигурации

Экспортируйте ноды, команды и скрипты перед рискованным изменением. Экспорт не
содержит секретов, поэтому после восстановления учётные данные нод задаются
заново. Проверьте файл перед импортом и сверьте количества созданных,
обновлённых и пропущенных объектов.
