# Добавление endpoint

Определите Pydantic boundary schemas, добавьте поведение service, создайте
тонкий route и подключите зависимости через Dishka. Укажите response model,
summary, description, tag, status и ошибки. Добавьте unit и integration tests,
экспортируйте OpenAPI, проверьте breaking changes и обновите оба языка, не
копируя полную schema в Markdown.
