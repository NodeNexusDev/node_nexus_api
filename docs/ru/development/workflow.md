# Workflow разработки

Создайте от `dev` ветку `feature/`, `fix/`, `refactor/` или `docs/`. Используйте
Conventional Commits, выполните локальную проверку и после review влейте ветку в
`dev`. Feature-ветки остаются локальными; push разрешён только для `dev` и
`main`. Не изменяйте `.gitignore` без явного разрешения.
