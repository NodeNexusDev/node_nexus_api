# Документация и перевод

Каждая актуальная страница имеет English и Russian версии с одинаковым
относительным путём. English canonical для identifiers и terminology; Russian
содержит полный перевод. Не переводите class names, paths, parameters,
environment variables, error names и commands.

Используйте task-oriented заголовки, проверенные команды, относительные ссылки
и admonitions для опасных действий. Обновляйте `source_revision` в обеих
страницах. Security и migration изменения требуют синхронного перевода.
