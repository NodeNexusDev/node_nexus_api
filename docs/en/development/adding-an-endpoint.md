# Adding an endpoint

Define Pydantic boundary schemas, add service behavior, expose a thin route, and
wire dependencies through Dishka. Specify a response model, summary,
description, tag, status, and documented errors. Add unit and integration tests,
export OpenAPI, inspect the diff for breaking changes, and update both language
guides without copying the complete schema into Markdown.
