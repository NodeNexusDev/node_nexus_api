# Manage nodes

Create a node with SSH connection data, verify connectivity, then use its UUID
for metrics and execution requests. List requests support offset pagination and
cursor pagination; do not mix both modes. Tags use AND matching when filtering.
Use Swagger UI for the current request and response schemas.
