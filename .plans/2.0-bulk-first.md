## 1. Цели и не-цели

**Цели:**
* `bulk-first` без `bulk` в пути — `plural + ids[]` в теле (`PATCH /nodes {updates}`, `POST /nodes/deletions {ids}`, `POST /commands/executions {command_ids, node_ids|tags}` `M×N≤100`), `207 Multi-Status` для partial (`succeeded>0 && failed>0`), `200` all ok, `422` all failed.
* Единая пагинация `?cursor&limit -> {items, next_cursor, has_more, limit}` `app/schemas/common.py:CursorPage` для всех коллекций (вместо `page&size` + `total` `app/schemas/common.py:14`).
* Единый `GET /{entity}/stats?group_by=day|hour|week|month` (без `group_by` = агрегат `ExecutionStatsResponse:6`, с = `buckets: MetricsBucket[]:51`), `GET /dashboard:62` + `GET /dashboard/metrics:74` + `GET /.../metrics` удалены.
* Docker полнота `61% → 95%` — vert `1 нода × N` `POST /nodes/{id}/docker/...` без fleet `POST /docker/bulk/*:36`, `+9` роутов `kill|update|archive(cp)|port|wait|push|history|prune|version` + compose персистент `compose_projects`.
* `notes` `app/models/note.py:13` → `description: Text` в `nodes|commands|scripts` + дроп `notes` (`NodeModel:20` без description, `CommandModel:25`/`ScriptModel:25` уже есть).
* `templates` `/api/v2/templates/*` с `GitHub + локальные + assets/`, `template_pack_id FK` в `commands|scripts`, bulk `207`, `409` без авторенейма.
* Унификация ошибок `ErrorResponse:32`, статусов, фильтров, envelope bulk.

**Не-цели (отложено на 2.1):**
* `merge` для `templates update` (в 2.0 `uninstall+install` с `WARN`).
* Streaming `docker events`, `docker save|load` tar.
* `search` bulk, `config` bulk.

* `v1` breaking без `410` — митиг `MIGRATION.md` `v1→v2` + `openapi-diff` + `tag v2.0.0` на `dev` + PR в `main` `versioning.md:62`, `curl -i /api/v1` → `404` с `ErrorResponse {code:"Gone", message:"Use /api/v2"}` через `app/main.py:161` `404` handler (единственный `410`-подобный tombstone на 1 релиз, затем убрать).
